# Versículos — Versículo do Dia

Este arquivo contém os versículos que serão usados na geração das peças.

## Regras de preenchimento

Cada versículo deve conter:

- ID
- Referência
- Versão
- Texto
- Status

O texto do versículo deve ser inserido exatamente como será publicado.

Não adaptar.
Não alterar pontuação.
Não trocar palavras.

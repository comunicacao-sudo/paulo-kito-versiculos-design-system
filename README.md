# Paulo Kito — Versículos do Dia

Design System para criação automatizada dos conteúdos
“Versículo do Dia” do Paulo Kito.

## Objetivo

Criar peças verticais para Instagram Stories mantendo uma
identidade visual consistente, contemplativa, sóbria e premium.

O sistema define:

- Direção de arte
- Tipografia
- Composição
- Fotografia
- Hierarquia visual
- CTAs de interação
- Regras para geração em lote com IA

## Formato

1080 × 1920 px
Proporção 9:16

## Estrutura do projeto

- `/design-system` — regras da identidade visual
- `/references` — referências visuais aprovadas
- `/content` — versículos e CTAs
- `/prompts` — instruções para geração
- `/output` — artes geradas

# Paulo Kito — Versículos do Dia

Você é responsável por criar as artes da série “Versículo do Dia” do Paulo Kito.

Antes de criar qualquer peça, você deve consultar e respeitar todos os arquivos deste repositório.

## Objetivo

Criar peças verticais para Instagram Stories com identidade visual consistente, contemplativa, sóbria e premium.

## Formato obrigatório

- 1080 × 1920 px
- Proporção 9:16
- Conteúdo pensado para Stories e Reels

## Regras obrigatórias

- Nunca alterar o texto do versículo.
- Nunca resumir o versículo.
- Nunca inventar referência bíblica.
- Nunca mudar a versão bíblica informada.
- Sempre preservar pontuação e sentido do texto fornecido.
- Sempre manter boa legibilidade.
- Sempre respeitar o Design System deste repositório.
- Não adicionar elementos decorativos desnecessários.
- Não usar imagens religiosas clichês.

## Hierarquia da peça

Cada arte deve conter:

1. “Versículo do Dia”
2. Referência bíblica + versão
3. Texto completo do versículo
4. CTA de interação

## CTA

Cada peça deve conter uma CTA curta e coerente com o versículo.

Exemplos:

- Se você crê, escreva: Amém.
- Recebe essa palavra? Responda: Amém.
- Essa palavra falou com você hoje?
- Envie para alguém que precisa ler isso.

Não repetir a mesma CTA em peças consecutivas.

## Comportamento esperado

Antes de gerar qualquer peça:

1. Leia as regras visuais.
2. Analise o comprimento do versículo.
3. Escolha a melhor composição.
4. Escolha uma CTA coerente.
5. Gere a peça respeitando o sistema.
6. Não improvise fora das regras definidas.
